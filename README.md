# Summit Forge Technologies website

The public website for Summit Forge Technologies LLC.

This is a deliberately small static site: semantic HTML, modern CSS, approved brand assets, and no runtime dependencies. It is designed to deploy to GitHub Pages at [summitforgetechnologies.com](https://summitforgetechnologies.com).

## Preview locally

Serve the repository root with any static file server, then open `index.html` through that server.

For example:

```sh
python3 -m http.server 4173
```

## Deploy

Pushes to `main` deploy automatically through the GitHub Pages workflow. The repository's Pages source should be set to **GitHub Actions**.

## Brand assets

The logo and symbol files in `assets/` are approved Summit Forge production assets. Do not redraw, re-typeset, recolor, or rearrange them.
